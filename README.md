# Key App

Key Engineering Chesterfield: Job Sheet, KEPO, Service and Parts List in one app.

Host this folder as a static site (GitHub Pages works). Keep all the files together.

## Added in this version
- Upload **every file in this folder** each time, including `version.json` and `sw.js`. When you upload a new `index.html` and `version.json`, the iPads show an "Update now" banner by themselves.
- `sw.js` is needed for the urgent-order alert bell (office only).
- Risk Assess tab: job specific risk assessments (ref numbers like RA-261112-DB01), saved on the iPad and shared with the team when signed in.
- My Jobs tab: engineers accept / hand back / finish jobs the office issues to them.
